Быстрый старт

Минимальный путь от регистрации до первого ответа клиенту в VK.

1

Войдите в кабинет

Используйте email и пароль, выданные администратором. После входа откроется главная панель компании.

2

Настройте ИИ-ассистента

Укажите тип бизнеса, услуги, стиль общения и правила поведения в разделе ИИ-ассистент.

3

Подключите VK

В разделе VK укажите ID сообщества, Access Token и настройте Callback API.

4

Проверьте подключение

В окне «Управление» нажмите Проверить подключение и отправьте тестовое сообщение в сообщество.

Совет Сначала подключите VK, затем настройте ИИ-ассистента — так бот сразу сможет отвечать на входящие сообщения.

ИИ-ассистент

ИИ-ассистент — единый центр настройки поведения бота. Здесь вы задаёте, как система представляется клиенту и какие данные собирает.

Основные настройки

  • Тип бизнеса — выберите шаблон (магазин, услуги, кафе и др.) или настройте вручную.
  • Услуги и цены — добавьте позиции, чтобы ассистент отвечал по вашему прайсу.
  • Стиль общения — дружелюбный, деловой или экспертный тон.
  • Правила поведения — уточнение бюджета, сроков, сбор контактов.

Дополнительные вкладки

  • Шаблоны сообщений — готовые фразы для типовых ситуаций.
  • Сценарии диалога — логика ветвления разговора.
  • Интеграции — связь с подключёнными каналами.
Важно Раздел ИИ-ассистента доступен после подключения VK — без интеграции бот не сможет принимать сообщения.

Интеграция VK

Подключение сообщества выполняется в разделе Настройка VK. Virexo использует Callback API для мгновенного получения входящих сообщений.

Access Token

Токен нужен для чтения и отправки сообщений от имени сообщества.

  1. Откройте ваше сообщество VK → Управление.
  2. Перейдите в Работа с API → Ключи доступа.
  3. Создайте ключ с правами: Управление сообществом, Сообщения сообщества.
  4. Скопируйте токен и вставьте в форму Virexo.
Безопасность Не публикуйте токен в открытом доступе. Если токен утёк — отзовите его в VK и создайте новый.

ID сообщества

Укажите числовой ID группы. Его можно найти в адресе страницы (club123456789 → ID 123456789) или в настройках сообщества. Подробнее в FAQ VK.

Callback API

Callback API позволяет VK отправлять новые сообщения в Virexo. Адрес сервера и ключи генерируются автоматически — вам нужно только скопировать их в настройки сообщества.

1

Подключите сообщество в Virexo

Заполните форму и нажмите «Подключить сообщество». Система сгенерирует Secret Key и Confirmation token.

2

Откройте «Управление» на карточке сообщества

Скопируйте Callback URL, Secret Key и Confirmation token.

3

Настройте VK → Callback API

Укажите адрес сервера, строку подтверждения и секретный ключ. Включите событие Входящее сообщение.

4

Нажмите «Настроить Callback API» в Virexo

Или выполните настройку вручную в панели VK — оба способа рабочие.

Callback URL для вашего аккаунта (копируется в разделе VK → Управление):

https://ваш-адрес.bizflow.ru/api/vkbot/webhook
Не нужно ничего настраивать вручную на сервере Virexo уже развёрнут и принимает webhook. Просто вставьте Callback URL из кабинета в настройки VK.
Поле Где взять Куда вставить
Callback URL Virexo → Управление VK → Callback API → Адрес
Confirmation token Virexo → Управление VK → Строка подтверждения
Secret Key Virexo → Управление VK → Секретный ключ
Access Token VK → Ключи доступа Virexo → форма подключения

Проверка подключения

После сохранения настроек откройте карточку сообщества → Управление → Проверить подключение.

Система проверит:

  • корректность ID сообщества и токена;
  • наличие Callback URL и confirmation token;
  • совпадение данных в VK и в Virexo;
  • доступность API VK.
Тест вживую Напишите сообщение в ваше сообщество VK с другого аккаунта — ответ должен прийти от ИИ-ассистента в течение нескольких секунд.

Диалоги и заявки

Когда клиент пишет в VK, Virexo создаёт диалог и карточку клиента. ИИ ведёт разговор, уточняет детали и формирует заявку.

  • Диалоги — полная история переписки.
  • Клиенты — профили с контактами и интересами.
  • Заявки — структурированные запросы от клиентов.

Разделы диалогов и заявок появятся в меню по мере подключения соответствующих модулей тарифа.

Частые вопросы

Бот не отвечает на сообщения в VK

Проверьте совпадение confirmation token и secret key, права токена на сообщения и включено ли событие «Входящее сообщение» в VK. Нажмите «Проверить подключение» в разделе VK.

Ошибка «Подключите VK» в разделе ИИ

Сначала сохраните настройки сообщества в разделе VK. ИИ-ассистент активируется только после успешной интеграции.

Где взять Access Token?

VK → Управление сообществом → Работа с API → Ключи доступа. Нужны права на управление сообществом и сообщения.

Можно ли подключить личный аккаунт?

Да, в форме есть режим «Личный аккаунт менеджера». Для бизнеса рекомендуем публичную страницу (сообщество).
